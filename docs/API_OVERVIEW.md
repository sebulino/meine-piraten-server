# meine-piraten.de API

The API reference lives in one place: the `/api` page of the running app.

- Production: <https://meine-piraten.de/api>
- Development: <http://localhost:3000/api>
- Source: [`app/views/pages/api.html.erb`](../app/views/pages/api.html.erb)

Update that page whenever an endpoint, parameter, permission or response
shape changes. It is the contract the iOS app is built against.

For the database schema, see [`db/schema.rb`](../db/schema.rb).
